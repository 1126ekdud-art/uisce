# Uisce Beatha — 웹페이지 시안

위스키 & 클래식 칵테일 바 **Uisce Beatha** (Since 2023)의 웹 시안입니다.
빌드 도구나 외부 의존성 없이, 브라우저로 HTML 파일을 열면 바로 보입니다.

| 파일 | 내용 |
| --- | --- |
| `index.html` | 바 소개 원페이지 |
| `menu.html` | 메뉴판 — `build_menu.py`가 생성 |
| `menu_data.py` | 메뉴 데이터. **가격·항목은 여기만 고치면 됩니다** |
| `build_menu.py` | `menu_data.py` → `menu.html` |

메뉴를 고친 뒤에는 다시 생성해 주세요.

```
python3 build_menu.py
```

## 이름

*uisce beatha*는 아일랜드어로 '생명의 물', 곧 증류주를 뜻합니다.
영국인들이 앞의 두 음절만 따라 부르면서 그 말이 오늘날의 whiskey가 되었습니다.
이 시안은 사라진 '생명' 대신 맨 앞의 **물**을 디자인의 중심에 두었습니다.

## 디자인 방향

- **색** — 위스키 바에서 흔히 쓰는 따뜻한 갈색 바탕을 뒤집었습니다.
  바탕은 우물물·젖은 석회암·구리 녹의 차가운 색이고, 페이지에서 유일하게
  따뜻한 색은 위스키(호박색)입니다. 그래서 메뉴판에서 가격과 도수가
  저절로 눈에 걸립니다.
- **글자** — 큰 제목은 명조 계열, 본문은 산세리프, 가격·도수·용량 등 숫자는
  고정폭 서체로 세 역할을 나눴습니다. 한글은 `word-break: keep-all`로
  어절 단위로 끊습니다.
- **레이아웃** — 소개 페이지 왼쪽에 고정된 **비중계 레일**. 술의 도수를 재는
  비중계 눈금을 본떠, 스크롤에 따라 수위가 차오르고 섹션 라벨이 실제 문서
  위치에 놓입니다. 1180px 미만에서는 숨깁니다.
- **움직임** — 히어로 배경은 캔버스로 그리는 물결 간섭무늬(코스틱)입니다.

## 메뉴판 (`menu.html`)

원본 메뉴 PDF 27쪽을 그대로 옮겼습니다.

| 분류 | 수량 |
| --- | --- |
| 시그니처 칵테일 | 6 |
| 클래식 칵테일 | 9개 기주 · 44종 |
| 위스키 & 스피릿 | 16개 분류 · 181종 |
| 테이스팅 코스 | 6 |
| 안주 · 맥주 · 시드르 | 11 |
| 보틀 (키핑) | 15 |

- **찾기** — 상단 검색창에 술 이름을 넣으면 전체에서 걸러 냅니다.
  한글·영문 모두 되고, 공백을 무시하므로 "글렌 피딕"으로도 "글렌피딕"이 잡힙니다.
  항목이 남지 않은 분류와 섹션은 통째로 접힙니다.
- **인쇄** — 인쇄하면 네비게이션이 빠지고 분류마다 페이지가 나뉩니다.
- 가격은 원본의 `18.` 표기를 `18,000`으로 폈습니다.
  60ml 가격이 비어 있던 항목은 `—`로 표시됩니다.

## 공통

- 라이트/다크 두 테마. OS 설정을 따르고, 우측 상단 버튼으로 직접 전환합니다.
- 반응형. 모바일에서 가로 스크롤이 생기지 않습니다.
- `prefers-reduced-motion`을 켠 환경에서는 배경 애니메이션과 등장 효과를 끕니다.
- 키보드 포커스 표시, 표 헤더 `scope` 지정 등 기본적인 접근성 처리.

## 원본에서 손본 것

메뉴 PDF를 옮기면서 아래를 바로잡았습니다. 되돌리려면 `menu_data.py`를 고쳐 주세요.

- 숫자 `1`이 알파벳 `l`·`I`로 들어가 있던 표기 — `Ardbeg l0Y` → `Ardbeg 10Y`,
  `Macallan I2Y` → `Macallan 12Y`, `Talisker I0Y` → `Talisker 10Y` 등.
- 브랜드 철자 — `Tanquary` → `Tanqueray`, `Bullet` → `Bulleit`,
  `O Ban` → `Oban`, `Prat Smoked` → `Peat Smoked`, `Eglair` → `Eagle Rare`,
  `Kilkerran CSt` → `Kilkerran CS`, `Strenth` → `Strength`.
- `크리스찬 드루앵 르 진`이 GIN과 CALVADOS 양쪽에 같은 가격으로 중복되어 있어
  GIN에만 두었습니다.
- 라세이(Raasay)는 실제로는 아일랜드(Island) 증류소지만, 원본대로 아일라에
  두었습니다.
