# UISCE — 바 소개 웹페이지 시안

아이리시 위스키 & 코디얼 바 **UISCE**의 원페이지 소개 웹사이트 시안입니다.
`index.html` 파일 하나로 끝나며, 빌드 과정이나 외부 의존성이 없습니다.
브라우저로 파일을 열면 바로 보입니다.

```
open index.html
```

## 이름

*uisce*는 아일랜드어로 '물'이고, 발음은 /ˈɪʃ.kə/ (이시커)입니다.
증류주를 뜻하던 *uisce beatha*(생명의 물)에서 앞 두 음절만 영어로 옮겨진 것이
오늘날의 whiskey입니다. 이 시안은 사라진 '생명' 대신 맨 앞의 '물'을
브랜드의 중심에 두는 것을 컨셉으로 잡았습니다.

## 디자인 방향

- **색** — 위스키 바에서 흔히 쓰는 따뜻한 갈색 바탕을 뒤집었습니다.
  바탕은 우물물·젖은 석회암·구리 녹의 차가운 색이고, 페이지에서 유일하게
  따뜻한 색은 위스키(호박색)입니다. 강조색을 한 곳에만 씁니다.
- **글자** — 큰 제목은 명조 계열, 본문은 산세리프, 가격·도수·시간 등
  숫자는 고정폭 서체로 세 가지 역할을 나눴습니다. 한글은 `word-break: keep-all`로
  어절 단위로 끊습니다.
- **레이아웃** — 왼쪽에 고정된 **비중계 레일**. 술의 도수를 재는 비중계 눈금을
  본떠, 스크롤에 따라 수위가 차오르고 각 섹션 라벨이 실제 문서 위치에 놓입니다.
  1180px 미만에서는 숨깁니다.
- **움직임** — 히어로 배경은 캔버스로 그리는 물결 간섭무늬(코스틱)입니다.
  저해상도로 그린 뒤 CSS로 확대해 가장자리를 번지게 합니다.

## 구성

| 섹션 | 내용 |
| --- | --- |
| 히어로 | 워드마크, 발음, 어원 한 문단, 영업시간 요약 |
| 01 소개 | 바의 성격과 운영 방식, 지표(좌석·보유 병 수 등) |
| 02 만드는 방식 | 물 → 보리 → 증류 → 숙성. 위스키 제조 순서에 맞춘 4단계 |
| 03 메뉴 | 시그니처 7종 · 위스키 17종(표) · 클래식 6종 · 논알코올 4종 · 안주 6종 |
| 04 공간 | 바 카운터, 테이블, 안쪽 방 |
| 05 방문 | 주소, 오시는 길, 영업시간, 하우스 룰 |

## 만든 것

- 라이트/다크 두 테마. OS 설정을 따르고, 우측 상단 버튼으로 직접 전환합니다.
- 반응형. 모바일에서 가로 스크롤이 생기지 않습니다.
- 메뉴 인쇄용 스타일. 인쇄하면 네비게이션과 배경 효과가 빠지고 메뉴만 남습니다.
- `prefers-reduced-motion`을 켠 환경에서는 배경 애니메이션과 등장 효과를 끕니다.
- 키보드 포커스 표시, 표 헤더 `scope` 지정 등 기본적인 접근성 처리.
